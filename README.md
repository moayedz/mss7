# الجهد المعرفي — Cognitive Load Tracker

منظّم يومي لطالب الطب يعمل من صفحة HTML واحدة، ويمكن تثبيته على شاشة iPhone الرئيسية.

- **المعركة الكبرى**: تكتب كل محاضرات اليوم، وتختار منها واحدة تخلّصها للآخر بثلاث مراحل (فهم أول ← تلخيص ← çıkmış/Anki). لما تخلص، تنتقل للتالية.
- **مهام منخفضة الطاقة**: ٣ مهام خفيفة كحد أقصى.
- **صندوق تفريغ الدماغ**: لتفريغ الأفكار المشتتة فوراً.
- **مواد Kurul 2**: Biyokimya، Biyofizik، Biyoistatistik، Tıbbi Biyoloji. المحاضرات من الجدول بتيجي بمادتها.
- **عدّاد الامتحان**: اضغط عليه لتغيير الموعد والاسم.
- **سجل آخر ١٤ يوماً**: كم مرحلة أنجزت ومن أي مادة، ومتى آخر مرة درست كل مادة (بإطار أحمر إذا مرّت ٤ أيام أو أكثر).

لتغيير المواد للكورول الجاي: عدّل `SUBJECTS` في `index.html`.

البيانات تُحفظ محلياً على الجهاز (localStorage)، والصفحة تعمل بدون إنترنت بعد أول فتح.

## التثبيت على iPhone

1. انشر المستودع على GitHub Pages: **Settings → Pages → Deploy from a branch** واختر الفرع والمجلد `/ (root)`.
2. افتح الرابط في **Safari** على iPhone.
3. اضغط زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

## مهام اليوم

قسم للمهام غير الدراسية (النادي، مواعيد، مشتريات). **المهام المتكررة** بتنضاف لحالها بالأيام اللي بتختارها، والمهام لمرة وحدة اللي ما خلصت بتنتقل لليوم اللي بعده.

## جدول الكورول

`schedule.js` فيه برنامج Kurul 2 (TIP1200) كامل: كل يوم بتنزل محاضراته لحالها بقائمة "محاضرات اليوم" مع مادتها ووقتها، وعدّاد الامتحان بيعدّ للعملي (9 ديسمبر) والنظري (11 ديسمبر).

بالأيام اللي ما فيها محاضرات (الويكند، Serbest Çalışma) بيطلعلك زرين: **دروس فاتتك** و**حضّر لليوم الجاي**.

زر **دروس فاتتك** بيعرض محاضرات الأيام اللي فاتت اللي لسا ما وصلت فيها للمرحلة الثالثة، عشان ترجعلها.

للكورول الجاي: استبدل `schedule.js` ببرنامجه، وعدّل `SUBJECTS` في `index.html` إذا تغيّرت المواد.
